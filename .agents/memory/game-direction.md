---
name: Game direction
description: Durable gameplay and presentation goals for this project.
---

The user wants a cute mobile-friendly boss-fight game with a fast, high-damage villain who remains defeatable, using animal hero portraits.

**Why:** A villain-only victory and unlimited hero revives undercut the requested high-stakes fight.

**How to apply:** Preserve a real player win path, finite survivability, clear dodge opportunities, and touch-first UI when changing the fight.
